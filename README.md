# java-calculator-precourse

## 문자열 덧셈 계산기 기능 목록

### 1. 프로그램 진입
- [X] 1.1 사용자가 문자열을 입력할 수 있도록 안내하는 문구 출력하는 기능
- [X] 1.2 사용자가 문자열을 입력하는 기능
  - [X] 1.2.1 입력값: 문자열

### 2. 문자열 분리
- [ ] 2.1 문자열 분리
  - [X] 2.1.1 기본 구분자(쉼표와 콜론)를 기준으로 분리하는 기능
  - [X] 2.1.2 커스텀 구분자를 기준으로 분리하는 기능
  - [ ] 2.1.3 예외처리: 구분자와 양수로 된 문자열이 아닌 잘못된 값 입력 시 IllegalArgumentException 발생 후 종료

### 3. 덧셈 계산기
- [X] 3.1 더하기 기능

### 4. 출력
- [X] 4.1 계산 결과를 출력하는 기능
