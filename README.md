# java-calculator-precourse
## 문자열 덧셈 계산기 기능 목록
### 1. 프로그램 진입 <br>
   - [ ] 1.1 사용자가 문자열을 입력할 수 있도록 안내하는 문구 출력하는 기능
   - [ ] 1.2 사용자가 문자열을 입력하는 기능
     - [ ] 1.2.1 입력값 : 문자열
     - [ ] 1.2.2 예외처리 : 구분자와 양수로 된 문자열이 아닌 잘못된 값 입력 시 IllegalArgumentException 발생 후 종료

### 2. 문자열 덧셈 계산기
 - [ ] 2.1 기본 구분자(쉼표와 콜론)를 기준으로 분리한 후 숫자를 합하는 기능
 - [ ] 2.2 커스텀 구분자를 기준으로 분리한 후 숫자를 합하는 기능

### 3. 출력 
  - [ ] 3.1 계산 결과를 출력하는 기능
